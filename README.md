# Songo'o

Le jeu de plateau Songo'o, par **Rihen Universe**, construit sur le moteur Nkentseu.
Ce dépôt ne contient pas le code : il sert à distribuer les **versions de test** (onglet *Releases*).

*The Songo'o board game by **Rihen Universe**, built on the Nkentseu engine. This repository holds no
source code: it distributes the **test builds** (see *Releases*).*

## Télécharger / Download
